# Календарь расходов

Семейный планировщик зарплаты и расходов. Сайт: https://iliakuntsevich.github.io/budget (GitHub Pages из ветки `main`, корень).

## Устройство

- Всё в `index.html` (разметка, стили, скрипт), сборки нет.
- `config.js` — адрес Supabase и публичный publishable-ключ.
- `supabase.js` — supabase-js 2.109.0 (UMD). `leaflet.js` / `leaflet.css` — Leaflet 1.9.4.
- Курс НБРБ сайт берёт сам из `api.nbrb.by`.
- Карта: тайлы `tile.openstreetmap.org` (CARTO не использовать — требует ключ), поиск адреса — Nominatim.
- PDF — печать браузера (`@media print`, блок `#printArea`).

## Данные

Таблица `public.planner_rows` (`id text pk`, `data jsonb`, `updated_at`, `updated_by`).
RLS: читать и писать может любой вошедший пользователь. Регистрация в Supabase выключена, пользователей двое. Изменения второго пользователя приходят через Supabase Realtime.

Каждая запись — отдельная строка:

| id | data |
|---|---|
| `settings` | `{display, salary, balances{cardByn, cardEur, cashByn}}` |
| `rates` | `{EUR, USD, date, source}` |
| `rec:<id>` | постоянный расход `{name, amount, currency, group, need, freq, day, wd, start}` |
| `one:<id>` | разовый `{kind, name, amount, currency, group, need, date, done}` |
| `ov:<recId@YYYY-MM-DD>` / `ov:<salary@YYYY-MM>` | правка одного платежа `{done, skip, amount}` |
| `task:<id>` | задача `{title, created, done, doneAt, place{lat, lng, label}}` |

## Правила

- Зарплата 2100 EUR 11-го числа; если 11-е на выходных — в пятницу перед ними.
- В день зарплаты она в прогноз не добавляется: в этот день вводятся остатки, где она уже учтена.
- Валюты EUR/USD/BYN, итоги в EUR по курсу НБРБ. Счёт списания не указывается, прогноз — по всем деньгам вместе.
- Все суммы на экране целые (внутри считаются точно); курс — 4 знака.
- Группы: Еда, Коля, Машина, Развлечения, Путешествия, БЦ, Медицина, Быт, Одежда, Личное, Прочее.
- Вид: обязательный / гибкий. Постоянный расход по умолчанию обязательный, разовый — гибкий.
- Частоты: неделя, 2 недели, месяц, полгода, год. Платёж можно отметить «оплачено», «пропустить» или задать сумму на этот раз.

## Интерфейс

Порядок блоков:
1. Деньги сейчас + плитки: Расходы до зарплаты, Обязательные до зарплаты, Останется к зарплате (с суммой в BYN), Курс НБРБ (с кнопкой обновления).
2. Задачи слева, Карта справа.
3. Календарь.
4. Общий список расходов за период.

**Календарь:** 3 месяца вкладками. В плитке дня расходы по строкам со свёрткой «▾ ещё N», «+» для добавления. Внизу слева серым — расходы дня в €, справа — остаток на вечер (синий ≥ 0, красный < 0).

**Общий список** (от зарплаты до зарплаты): свои вкладки, следуют за календарём; группировка по группам; колонки Название / Вид / Стоимость €; оплаченные скрыты. Итоговая строка «осталось оплатить · обязательные · гибкие · Разница», где Разница — прогнозный остаток накануне следующей зарплаты (совпадает с плиткой «Останется к зарплате»), зелёная/красная. Кнопка «Скачать PDF».

**Задачи:** кружок — выполнено (зачёркнута, уходит вниз, повторное нажатие возвращает), крестик — удалить. У задачи может быть место; на карте пронумерованные метки, кнопки «Маршрут в Google Maps» и «Где я».

## Проверка изменений

Открывать страницу в Playwright с поддельным клиентом Supabase в памяти (`window.supabase` с `auth` / `from` / `channel` поверх localStorage) и копией данных. Смотреть ширину 1180 и 400 px. Доступ к настоящей базе для работы не нужен.
